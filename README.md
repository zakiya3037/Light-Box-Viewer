# Lightbox Gallery

## Overview
The Lightbox Gallery is a simple web project built using HTML, CSS, and JavaScript. It displays image thumbnails that users can click to view their full-size versions in a lightbox overlay.

## Features
- Displays three image thumbnails in a gallery.
- Opens a full-size image when a thumbnail is clicked.
- Automatically converts thumbnail image URLs to full-size image URLs.
- Displays the image in a full-screen overlay.
- Closes the lightbox using the close button or by clicking the background.
- Uses CSS to style and position the lightbox.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click any thumbnail to view the full-size image.
5. Click the close button or the lightbox background to close the preview.

## What I Learned
- Selecting HTML elements using `querySelector()` and `querySelectorAll()`.
- Handling click events with `addEventListener()`.
- Using `forEach()` to add event listeners to multiple images.
- Changing CSS styles using JavaScript.
- Updating an image's `src` attribute dynamically.
- Using `replace()` to modify image URLs.
